# Hadoop

This domain covers the HDFS and YARN concepts required to understand Hadoop's
storage and cluster-management model and how Spark runs on YARN.

Planned implementation order:

1. Pseudo-distributed Hadoop
2. Docker Compose HDFS and YARN cluster
3. HDFS and YARN operations and failure exercises

HDFS on Kubernetes and a dedicated Hadoop EC2 cluster are outside the current
scope.
